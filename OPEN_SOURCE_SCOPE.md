# Open-Source Scope

AIR's public repository is licensed under the Apache License 2.0 unless a file
or directory explicitly says otherwise.

That license applies to the code and documentation actually published in this
repository. It does **not** automatically license:

- private Superior MI Labs repositories;
- unpublished research code or experiments;
- datasets or model weights;
- hosted services or deployment infrastructure;
- private tools, agents, orchestration, or business systems;
- trademarks, logos, or brand identity beyond customary descriptive use;
- future proprietary components that are not included here.

This lets people use, study, test, modify, and redistribute the public AIR code
under Apache-2.0 while keeping unpublished/proprietary Superior MI work outside
the scope of this repository.
