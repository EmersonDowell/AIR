# AIR

**Adaptive Inference Runtime**

AIR is a Superior MI Labs research program exploring adaptive inference,
runtime architecture, hardware-aware execution, and increasingly general
intelligent computation.

This Hugging Face Space is the public research and demonstration surface
for AIR.

The canonical engineering repository is maintained by Superior MI Labs on
GitHub:

https://github.com/Superior-MI-Labs/AIR
